# Banco de Dados — Atividades SQL

Repositório contendo atividades práticas desenvolvidas na disciplina de **Banco de Dados**, com scripts SQL voltados para modelagem, criação de estruturas, consultas e aplicação de conceitos fundamentais de bancos relacionais.

## Estrutura do Repositório

### Arquivos de Modelagem e Simulação de Cenários

* **BD_Concessionaria.sql**
  Estruturação de banco de dados para gerenciamento de concessionária.

* **BD_Cyber.sql**
  Modelagem de banco de dados aplicada a um cenário de cibersegurança.

* **BD_Supermercado.sql**
  Estrutura para gerenciamento de operações de supermercado.

* **BD_corp.sql**
  Simulação de ambiente corporativo com entidades organizacionais.

* **BD_loja.sql**
  Modelagem de sistema para controle de loja.

## Arquivos de Estudos Específicos

* **exemplo_join.sql**
  Exemplos práticos de utilização de operações JOIN.

* **exemplo_senhas.sql**
  Exemplos relacionados ao armazenamento e manipulação de senhas.

## Conceitos Aplicados

Durante o desenvolvimento das atividades foram trabalhados conceitos como:

* Modelagem relacional
* Criação de tabelas
* Chaves primárias e estrangeiras
* Relacionamentos entre entidades
* Consultas SQL
* Operações JOIN
* Integridade referencial
* Estruturação lógica de bancos de dados

## Tecnologias Utilizadas

* SQL
* SGBDs relacionais
* Ambiente acadêmico para prática de banco de dados

## Objetivo

Este repositório tem como finalidade consolidar o aprendizado prático da disciplina, servindo como registro das atividades desenvolvidas e apoio para consultas futuras.
